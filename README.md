# IDPVMS


**IDPVMS** is an offline, end-to-end media management system developed using **Flask** and **PostgreSQL**, designed specifically for managing photography and videography assignments at secure institutions like BARC (Bhabha Atomic Research Centre).

## 🚀 Features

- 📅 **Event-based job management**
- 📷 **Photographer and videographer assignment module**
- 🔐 **Role-based secure login and access control**
- 🧠 **Keyword tagging and media search**
- 💾 **Offline storage with backup support**
- 📊 **Admin dashboard for real-time monitoring and reports**
- 🧾 **Post-job album review and download options**

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, Bootstrap, Jinja2
- **Database**: PostgreSQL
- **Tools**: Git, GitHub, pgAdmin, Windows OS

## 📌 Use Cases

- Secure institutions with controlled internet access
- Event photographers/videographers managing bulk data
- Organizations needing structured media archives

## 🛡️ Security Features

- Role-based authentication
- Offline media storage
- Controlled access based on user levels
